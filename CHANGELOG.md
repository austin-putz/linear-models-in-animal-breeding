# Changelog

Every released version of the book, newest first. Each entry is written once, at release time,
and is the book's errata: **Corrected** lists results that changed (a number, an equation, an R
output, a claim), **Changed** lists content that was added or rewritten, **Fixed** lists typos and
cosmetics. Reporters are credited in the entry their report caused.

The release workflow copies a version's section into the GitHub release notes, so the heading
must be exactly `## [X.Y.Z] - YYYY-MM-DD`.

## [0.1.0] - 2026-09-12

First tagged version. The book is under construction: Chapter 1 is drafted and every other
chapter and appendix is a placeholder carrying its title and learning objectives. This release

content it will carry is written.
