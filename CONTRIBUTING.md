# Contributing

Everything about reporting an error, fixing one yourself, asking a question, or suggesting a
change is on one page of the book, so that it is the same for readers of the website and the PDF:

**<https://austin-putz.github.io/linear-models-in-animal-breeding/reporting.html>**

The short version: a wrong number or equation is an **issue** (use the *Error in the book* form);
a typo you are willing to fix is a **pull request** from the *Edit this page* link; a question or
a suggestion is a **discussion**. Say which version you read — it is in the footer of every page.
